# Pulse Centrifuge

<Row gap="16">
  <BlockImage id="ae2cs:pulse_centrifuge" scale="8" />
</Row>

The **Pulse Centrifuge** separates one item input into up to four deterministic outputs.
Its recipes are datapack-defined and consume a configured total amount of AE energy.

The machine supports Speed Cards, up to two Meteorite Overclock Cards, and
**[Side Configuration](side_config.md)** for automated input and output.

No processing recipes are bundled with the initial machine framework.
