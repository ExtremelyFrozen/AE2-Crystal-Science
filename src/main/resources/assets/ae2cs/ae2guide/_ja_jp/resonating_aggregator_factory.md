# 共鳴水晶収集工場

<Row gap="16">
  <BlockImage id="ae2cs:resonating_aggregator_factory" scale="8" />
</Row>

**共鳴水晶収集工場**は、[水晶収集機](crystal_aggregator.md)と同じレシピを使うバッチ加工機です。高度な部品や水晶の種をまとめて生産します。

## インベントリと加工

- 入力は **3×3 の9スロット**、出力は **3スロット**。
- 流体の入力・出力タンクは、それぞれ **16,000 mB**。タンクの操作ボタンで容器からの移送が可能です。
- 完成したレシピごとに、素材・流体・エネルギーを全量消費します。

| 隕石カードの枚数 | 最大バッチ数 | 目標周期 |
| --- | --- | --- |
| 0 | 8 | レシピのエネルギー量に応じて進行 |
| 1 | 32 | 64 tick |
| 2 | 64 | 16 tick |
| 3 | 256 | 4 tick |
| 4 | 1024 | 1 tick |

実際の処理数は、素材・流体・電力・出力空間で制限されます。不足時は停止し、支払い済みのエネルギーは現在のバッチに保持されます。

---

## アップグレードと保管容量

- 4個の専用スロットに、最大 **4枚の<ItemLink id="ae2cs:overload_card" />**を装着できます。
- 2個の専用スロットに、最大 **2枚の<ItemLink id="ae2cs:resonating_stacking_card" />**を装着できます。
- 各スロットは1枚まで。通常の速度カードには対応しません。
- アップグレード欄にカーソルを合わせると、対応カードと機械全体の上限を表示します。

通常64個まで重なる物品は、スタックカード0・1・2枚で、1スロットあたり **64・256・1024個**になります。元の上限が小さい物品は比例して増加し、重ねられない物品は1個のままです。カードを外すと容量超過になる場合は、先に余分な物品を取り出してください。

## 操作と自動化

左側の「**?**」ボタンで専用ガイドを開き、その隣のボタンで[側面設定](side_config.md)を開きます。各面の搬入・搬出や自動搬入・自動搬出を設定できます。
