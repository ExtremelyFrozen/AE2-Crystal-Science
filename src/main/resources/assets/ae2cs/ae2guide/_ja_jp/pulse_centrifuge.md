# パルス遠心分離機

<Row gap="16">
  <BlockImage id="ae2cs:pulse_centrifuge" scale="8" />
</Row>

**パルス遠心分離機**は、1種類の入力アイテムを1から4種類の確定した出力に分離します。
レシピはデータパックで定義され、設定された合計AEエネルギーを消費します。

速度カード、最大2枚の隕石オーバークロックカード、および自動入出力用の
**[側面設定](side_config.md)**をサポートします。

初期の機械フレームワークには処理レシピが同梱されていません。
