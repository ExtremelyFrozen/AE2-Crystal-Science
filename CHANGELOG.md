# Changelog

## 1.2.2

### English

- Added AE2WTLib integration for the Wireless Resonant Crafting Encoding Terminal.
- Added recipes for installing the Wireless Resonant Crafting Encoding Terminal into the Wireless Universal Terminal and combining it with other wireless terminals.
- Expanded resonant processing pattern capacity to 144 input slots and 36 output slots.
- Fixed Forge Energy charging support for the Wireless Resonant Crafting Encoding Terminal.
- Expanded Meteorite Overclock Card support to compatible AECS machines, with 4-tick operation using one card and 1-tick operation using two.
- Adjusted the Meteorite Pattern Provider to accept up to four Meteorite Overclock Cards, with each card adding 128 parallel crafting requests.
- Fixed an incorrect scrollbar texture in the Ender Emitter frequency menu.
- Added Overload Crystal Seed recipes for the Crystal Aggregator and Lightning Simulation Chamber.
- Added JEI and EMI recipe navigation and ingredient transfer support to AECS processing machines.
- Added guide pages for the Mirror Pattern Provider and Resonant Crafting Encoding Terminal, and corrected the Meteorite Pattern Provider guide.
- Adjusted the Ender Emitter interface.
- Added seed, crystal processing, processor, charging, stonecutting, and cross-mod machine recipes.
- Adjusted the Ender Emitter, crystal storage block, charged overload crystal block, and Circuit Etcher recipes.
- Removed obsolete crafting recipes for energized and data crystal seeds.
- Updated the Purified Overload Crystal texture and refined Resonant Crafting Encoding Terminal mode button alignment.
- Fixed Data Energistics blank-pattern proxy interaction and network inventory display in the Resonant Crafting Encoding Terminal.
- Added conventional Data Crystal compatibility for Purified Data Crystals.
- Expanded Resonating Pattern Provider target assignments from 81 to 144 inputs.
- Standardized the Simplified Chinese name of the Entropy Variation Reaction Chamber.
